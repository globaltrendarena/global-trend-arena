Repo Auto-Scan (Cloudflare Worker)

Not connected

A static host can't list its own folders at runtime, so this Worker is the bridge: it calls the GitHub Contents API for admin-modules/ and pages/ and returns a plain JSON list of files, so new files dropped into the repo can be found automatically instead of hand-edited into config.json. Deploy workers/repo-scanner.js (included in this build) to Cloudflare Workers with a GITHUB_TOKEN secret, then paste its URL below.

Everything on this page currently saves to localStorage in your browser (key ic_site_config), so it won't sync across devices or survive a cleared cache. The planned upgrade is a site_config table in a real backend — swap the ApiConnect.storage read/write functions below for real API calls and every save/load call site keeps working unchanged.
